# PCB 黑白纹理文件（六边立方体 / 菱形镶嵌）— 方形版
# 尺寸：100mm × 100mm（正方形）  |  斜线已用直线拟合矢量化（无毛刺）

## 一、本版变更
- 尺寸由「身份证比例」改为 **正方形 100mm × 100mm**：
  - **SVG**：`width="100mm" height="100mm"`（viewBox 1600×1600），导入即 100×100mm；
  - **PNG**：1181×1181 像素 **@300dpi = 100.0mm × 100.0mm**。
- 图案对原图做**中心裁切为正方形 + 等比缩放**，不变形，居中显示。
- 继续使用 **potrace 直线拟合**（`alphamax=0`）矢量化：斜边为长直线，无阶梯毛刺。

## 二、SVG 与 PNG 导入的区别（重点）
| 维度 | SVG（矢量 · 形状 Shape） | PNG（位图 · 图片 Image） |
|---|---|---|
| 本质 | 数学路径，可无限放大不失真 | 像素点阵，放大会有锯齿/模糊 |
| 导入类型 | 选「形状」(Shape)，得到**可编辑的多边形/走线** | 选「图片」(Image)，得到一个**位图对象** |
| 放大到 100mm | 边缘始终锐利，斜线笔直 | 有可能出现像素锯齿（分辨率 1181px/100mm≈300dpi，够用但不如矢量） |
| 可编辑性 | 边缘即走线/铜皮，可继续布尔、拉伸、改层 | 通常不能直接编辑形状，只能整体放置/缩放 |
| 适合场景 | 想要的几何纹理、规整直线图案 **★推荐** | 位图照片、超细密纹理、矢量导入掉线时的备用 |
| 文件大小 | 较小（几十~几百 KB）且有大量节点时较大 | 固定按像素，通常更小 |
| 嘉立创EDA 表现 | 导入为「形状」后按面/走线处理，最贴近制板 | 导入为「图片」后按图像处理，用于铜层需二值化清晰 |

> 结论：**规整几何图案（本目录）优先用 SVG + 形状导入**，边缘最锐利、最接近"铜皮轮廓"；
> 仅当矢量导入后线条缺失/报错时，改用同名 **PNG + 图片导入** 兜底。

## 四、导入步骤（嘉立创EDA → Top Copper）
1. PCB 编辑界面 → **放置 → 图片 / Image**（专业版：**工具 → 导入图片**）；
2. **导入类型**：SVG 选「形状 (Shape)」；PNG 选「图片 (Image)」；
3. 选择 `svg_vector/`（推荐）或 `png_black_copper/` 中的文件；
4. **所在层**：`Top Copper`（顶层铜）；
5. 尺寸填 **100mm × 100mm**（文件已是此比例，直接确认即可）；
6. 黑白反了勾 **反相 (Invert)**；容差尽量调小以保留细节。

## 五、格式与限制
- 支持：SVGZ / SVG / PNG / JPG / JPEG / JFIF 等；单文件建议 ≤ 1~2MB；
- 本目录 SVG：`version="1.1"`、`width/height` 带 `mm`、无背景 `<rect>`。

> 提示：pcb_06 / pcb_08 / pcb_09 为极细密图案，矢量形状导入后若线条缺失较多，请改用同名 PNG。
