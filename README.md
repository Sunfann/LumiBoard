> 把插画变成会发光的 PCB 艺术品：从卡面设计到嘉立创下单的一站式「PCB 艺术卡牌工坊」。

**鎏光板绘**（LumiBoard，内部代号 Card Forge Studio / 卡牌工坊）是一个**纯前端、单文件、零依赖**的 PCB 艺术卡牌设计工具：在浏览器里完成卡面设计，一键把插画拆分为符合真实生产工艺的 **顶层铜 / 顶层阻焊 / 底层阻焊 / 彩色丝印** 图层，可进入**三维成品模拟**观察七层压合后的实物效果，并生成嘉立创EDA 专业版放置脚本按真实毫米尺寸 1:1 落板，导出即可下单打样。

名字由来：**鎏**＝沉金（ENIG）工艺的金色，**光**＝背光透出的画面，**板**＝PCB 电路板（也谐「板绘」），**绘**＝创作。

## ✨ 功能特性

### 🎨 卡面设计
- **单卡设计 / 批量生产 / 生产总览** 多视图工作台，顶部标签页一键切换
- 角色图片、卡面文案、稀有度配色、背景边框、漫画分镜拼贴、图标贴纸
- 字体样式与大小、合成特效与调色、角色摆放、元素显示/删除、快捷操作
- **助手**标签页提供 AI 提示词工坊，辅助快速出图与批量生成

### 🏭 多层图层 1:1 导出（工艺路线版）
- 一键拆板：**顶层铜 / 顶层阻焊 / 底层阻焊 / 彩色丝印** 四层
- 极性与真实生产一致：铜/丝印＝正片（黑＝有图元），阻焊＝负片（黑＝开窗）
- **分层 PNG（ZIP）导出**，可附板框轮廓参考图
- 生成嘉立创EDA 专业版「高级 → 运行脚本」脚本：四层按设定 mm 尺寸 **1:1 放置**，四角带对齐锚点保证重合

### 🔬 成品效果模拟（3D 成品卡片）
- **七层程序化模型**：顶层丝印 / 顶层阻焊 / 顶层铜箔 / FR-4 基板 / 底层铜箔 / 底层阻焊 / 底层丝印 逐层堆叠，机位与真实压合顺序一致
- **沉金金属浮雕**：方向光 + 浮雕法线 + 镜面高光，呈现雕刻金属质感
- **背光透光**：非线性透光曲线，亮部透光、暗部遮光，模拟真实点灯效果
- **金属扫光**：一束高光沿板面自左向右线性扫射而过，随工艺路线自动标注为「金属扫光 / 点亮背光」
- **彩色丝印半透叠印**：背光区油墨作为透色片，颜色与背光/金属光泽共存
- **档案终端**：整卡 + 七层 + 板边轮廓共 **9 条档案**，切换档案时固定当前视角，只切换层级
- 阻焊颜色、表面处理即时切换预览
- WebGL 不可用时**自动降级**为 2D 静态输出，永久兜底

#### 3D 观察操作
| 按键 | 功能 |
| --- | --- |
| `E` | 拆解 / 合拢视图 |
| `F` | 翻面（按层序 1→7 逐层错开翻转） |
| `空格` | 点亮背光 |
| `A` | 自动巡览 |
| `M` | 标定预设 |
| `←` / `→` | 上一机位 / 下一机位 |
| `↑` / `↓` | 上一档案 / 下一档案 |
| `I` | 档案目录 |
| `⇐` | 回主机位 |

- **四轴自由展开**：`⤢ 对角` / `↔ 横展` / `↕ 竖展` / `⊙ 纵深` 四个方向预设，随时自由切换层叠展开方向
- **逐层拾取**：在任一展开方向上**单击某一层**即选中该层，相机自动聚焦将其置于视觉中心并置顶展示，档案卡片同步显示该层档案
- **双击复位**：**双击某一层**恢复选中前的显示状态；在**其他任意位置双击**恢复初始状态
- **介绍卡片**默认透明，仅在鼠标悬停、点击或选中时淡入显示；透明态下 `pointer-events:none`，不遮挡画布操作
- 3D 视图状态（机位 / 拆解 / 翻面 / 背光 / 巡览 / 档案）属**观察行为，不进入撤销栈**

### ✅ 工艺校验（DRC）与下单参数
- 最小线宽检查（≥0.15mm，DPI 建议 ≤169）
- 路线专属校验：透光画板厚、彩色丝印「白阻焊 + 沉金」硬性要求、层映射冲突提示
- 自动生成下单参数摘要（阻焊颜色 / 表面处理 / 板厚）

## 🚀 快速开始

1. 下载 `LumiBoard.html`，用浏览器直接打开（推荐 Chrome / Edge）
2. **无需安装、无需联网、无需构建**，全部逻辑与图标均内嵌于单个 HTML 文件
3. （可选）将文件重命名为 `index.html`，即可通过 GitHub Pages 在线分享

## 📖 完整工作流

1. **设计卡面**：上传角色图，排版文案、边框、贴纸，完成调色
2. **设定物理尺寸**：宽/高 mm（或「尺寸跟随卡牌」）
3. **选择工艺路线**：一键自动套用层映射与下单参数
4. **预览验证**：分层预览 + 3D 成品模拟 + DRC 工艺校验
5. **导出**：分层 PNG（ZIP）
6. **落板**：生成 EDA 放置脚本 → 嘉立创EDA 专业版 → 高级 → 运行脚本 → 粘贴运行
7. **下单**：按「下单参数摘要」在嘉立创填写阻焊颜色、表面处理、板厚

## 🧾 下单参数速查

- **彩色丝印**：必须使用 **白色阻焊 + 沉金 ENIG**（嘉立创彩色丝印工艺硬性要求，否则偏色发黑）
- **透光画**：板厚建议 **0.6~0.8mm**（FR-4 透光性随厚度衰减）
- **最小线宽 ≥0.15mm**，导出 DPI 建议 ≤169
- 最终以嘉立创工艺审核结果为准

## 🔧 技术说明

- 纯 HTML + CSS + 原生 JavaScript，**零依赖、零构建**；3D 成品模拟基于内嵌 Three.js
- Canvas 2D 逐像素合成：层映射、分层预览、成品模拟均在本地完成
- 界面图标全部 base64 内嵌，无外部资源请求
- 3D 视图采用**按需渲染**：完全静止时跳过重绘，省电且交互帧更稳
- 正反面分层展开方向经翻转角补偿（旋转解耦），保证正反面展开方向一致
- 2D → 3D 切换时重建纹理，确保 3D 显示与当前 2D 卡面一致
- 兼容现代桌面浏览器（Chrome / Edge / Firefox / Safari）
